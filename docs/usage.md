# 使用说明

## 完整操作流程

首次打开 → 添加技能 → 设置三档目标 → 选择练习方式与档位 → 开始 → 完成并填写结果 → 核对提交 → 查看历史与成就。

### 添加和管理技能

每个技能拥有自己的目标、记录和奖励。次数默认 15/30/45，范围 1～999；时间默认 15/30/45 分钟，范围 5～120 分钟，以 5 分钟递增。低、中、高必须逐级增加。这些默认值只用于便捷设置，不是科学训练标准。

名称最多 20 字且不能重复，包括已归档的技能。重命名保留记录；归档从首页隐藏但可恢复；删除需要确认，永久清除该技能、练习和兑现记录。练习期间不能修改目标。

### 次数模式

自行完成目标次数，不需要逐次点击 App。时分秒显示有效练习时长。完成目标后填写正确次数，错误次数自动等于目标次数减去正确次数。未完成目标请选择取消。

### 时间模式

时分秒显示剩余时间。到点前可暂停或取消，到点后才可确认完成。填写正确次数和错误次数。到点不自动生成记录。

两种模式都支持暂停，暂停时间不计入练习。锁屏或切后台仍继续计时；系统杀死进程或手机重启会丢弃未提交轮次。填写结果和核对期间也不能开启另一轮练习。

### 结果与统计

正确、错误均为非负整数，合计必须大于 0。提交前可调整，提交后不可修改，不可补录历史。取消不计达标和奖励。跨午夜按点击完成练习时的当地日期归属。

每项技能每天首次提交有效结果增加一个达标日；同日多轮都计入准确率，但不重复增加达标日。准确率 = 总正确次数 ÷ 总次数，不平均各轮百分比。无记录显示“—”；全部错误的有效记录显示 0%。

首次提交开启独立七天统计周期，第七个自然日结束后解锁历史和奖励兑现；不要求连续达标七天。漏练不清零。历史支持最近 7/30/365 天和全部。

阶段奖励在累计达标 7、14、28、56、84 天解锁，之后每增加 28 天解锁新阶段；需手动兑现。每满 28 个达标日另赠一张技能专属兑换卡。奖励由用户自行安排，无实物发货或现金价值承诺。

### 设置与数据

主题可跟随系统、浅色或深色。交互音效控制按钮与开始/暂停/取消/结束语音，到点音独立控制，实际音量取决于媒体音量与系统通知设置。减少动画设置会影响倒计时动效。

每日提醒默认关闭。开启后按本机时间安排；当天全部未归档技能达标时跳过。通知权限、精确闹钟权限和省电限制可能影响提醒。Web 不提供可靠的后台提醒。

数据保存在本机，无登录、云同步、手动导出或自动备份。更新应覆盖安装，勿卸载。换手机、清除数据、卸载可能导致不可恢复的数据丢失。
